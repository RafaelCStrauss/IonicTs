# Aplicativo Ionic e Vue com Integração Supabase

Este repositório contém um aplicativo móvel desenvolvido com Ionic e Vue.js, integrado ao Supabase para gerenciar a autenticação de usuários e o armazenamento de dados. O projeto foi construído com o objetivo de aprimorar os fundamentos em desenvolvimento frontend e mobile.

## Tecnologias Utilizadas

* [Ionic Framework](https://ionicframework.com/) - Framework para desenvolvimento de aplicações multiplataforma.
* [Vue.js 3 (Composition API)](https://vuejs.org/) - Framework progressivo para construção de interfaces.
* [Supabase](https://supabase.com/) - Plataforma de backend para autenticação e banco de dados.
* [Ionicons](https://ionicons.com/) - Biblioteca oficial de ícones do Ionic.

## Processo de Desenvolvimento

O desenvolvimento deste projeto fundamentou-se em uma abordagem prática e estruturada:
* Suporte Tecnológico: Utilização de ferramentas de inteligência artificial para otimização de código, estruturação de componentes e padronização de estilos (CSS/Flexbox).
* Pesquisa e Documentação: Consulta recorrente à documentação oficial do Supabase e do Ionic para a implementação correta dos fluxos de sessão, autenticação (`getUser`) e tratamento de dados.

## Funcionalidades Implementadas

* Cadastro de Usuários: Registro utilizando e-mail, senha e nome completo, com persistência de metadados no Supabase.
* Autenticação: Sistema de login com validação de credenciais.
* Painel Principal (Dashboard): Exibição dinâmica do nome do usuário autenticado, obtido diretamente da sessão.
* Gerenciamento de Sessão: Funcionalidade de encerramento de sessão (*logout*) com redirecionamento automático para a tela de autenticação.
